# EMBER ATLAS

エンバーストーリアの所持・育成・研究・建設を記録する攻略アプリ。v0.3の限定テスト向けです。

## 開く

このフォルダーで `npm start`、または `起動.ps1` を実行し、[アプリ](http://localhost:5174/)を開きます。Node.js 20以上が必要です。依存パッケージのインストールやビルドは不要です。

- [拠点アビリティ](http://localhost:5174/#baseAbilities)
- [使い方ガイド・6ステップのチュートリアル](http://localhost:5174/#guide)
- [管理者ワークスペース](http://localhost:5174/admin.html#admin)

ローカル起動はこのPCからのみ利用でき、ログイン不要です。Webの限定公開は参加者用と管理者用のパスワードを分ける方式です。設定は[限定テスト公開の手順](docs/TEST_RELEASE.md)を参照してください。静的ファイルの公開だけでは認証は働きません。

GitHub Pagesで公開する場合は、このREADMEとアプリ本体を含むリポジトリがPublicになり、URLを知る人は誰でもアプリを開けます。GitHub Pagesではサーバー側ログインは使われず、個人の記録は各自のブラウザー内に保存されます。公開用ワークフローは`main`への反映後に`public/`を自動配信します。

### GitHub Pagesの更新

Codexでファイルを修正しただけでは、公開サイトには反映されません。変更を`main`ブランチへコミットしてGitHubにPushすると、GitHub Actionsが`public/`を再配信します。Actionsタブで「Deploy static app to GitHub Pages」が成功した後、同じ公開URLを再読み込みしてください。Codexには「この変更をGitHub Pagesへ反映して」と依頼できます。

## 利用者向けの機能

- エンバース72人：属性・兵種・スキル効果で検索、所持・現在と目標のスキルLvを記録。
- 武具197種：G1〜G6の効果比較、複数個体・サブアビリティの管理。10月追加の3種を収録。
- メモリ82種：固定効果・生成費用・入手先・課金条件の検索、同種の複数管理と複製。
- 研究419項目と施設建設：現在Lv、計画、必要資源・時間、施設Lvに対応する外観。
- 拠点アビリティ：内政・軍事・魔獣討伐、検索、獲得済み・要確認の絞り込み、20項目単位の一覧とゲーム内数値との照合。
- レイド武具、素材倍化率・採集の計算、育成ノート、同盟向けファイル共有。
- バックアップの書き出し・復元、複数プレイヤーの切り替え。

[参加者向け操作ガイド](docs/USER_GUIDE.md)も用意しています。共通データの編集・取り込み・確認資料は管理者画面へまとめました。管理者の変更は現在のブラウザー内に保存され、他の利用者には自動配信されません。

## 個人データの保存

各ブラウザー内に保存します。アカウント別のクラウド保存・自動同期はありません。ブラウザー、プロファイル、URLが変わると別の保存先になります。普段の記録を引き継ぐときは、元の画面の「記録とバックアップ」で書き出し、移行先で復元してください。

localhostと127.0.0.1も別扱いです。ブラウザーのサイトデータを消す前にバックアップしてください。全体バックアップには自分用メモや仲間の記録も含まれるため、同盟員に渡す場合は同盟ルームの共有ファイルを使います。

## 共通データと確認範囲

PC版ゲーム設定と画像を共通JSONに収録しています。ゲームのインストールがないPCでも使用できます。抽出元の識別情報・差分は監査ファイルに記録し、ゲームのキャッシュ原本や認証情報は配布に含めていません。

未確認値は0で補いません。メモリ固定効果2種・個別入手先5種・抽選候補や確率、研究と施設の一部前提条件は未確定です。必要時間や資源には設定データだけでは確定できない端数処理などもあり、計算画面の条件を確認してください。

## 開発・検証

ES modules + CSS + Node HTTPサーバーで動作します。

`npm test`：集計、計算式、所持品・共有・バックアップ用データ、画像参照、限定公開の認証制御を検証します。

公開先と本番用パスワードは未設定です。公開URL決定後にHTTPS環境でログイン・保存・復元を再確認してから参加者に案内してください。
