# EMBER ATLAS テスト版・使い方

アプリ右上の「使い方」、またはメニューの「使い方ガイド」から、7ステップのチュートリアルをいつでも開けます。

## 1. 最初の設定

限定公開版は、案内されたURLで「参加者」を選び、参加者用パスワードでログインします。右上の名前を押して、自分のプレイヤー名を登録してください。まずは育成中のエンバース1人だけの登録で構いません。

記録は、使っているブラウザーとURLごとに保存されます。毎回同じブラウザーで開き、URLをブックマークしておくと便利です。

## 2. エンバースの育成

「エンバース」でキャラを選び、「所持している」をチェックします。現在と目標のスキルLvを入力し、「記録を保存」を押してください。MAXボタンでまとめて入力もできます。スキルから解放されるコア段階は自動で計算します。

スキルの効果を調べるときは「スキル・コア」タブを使います。図鑑の初期画像はG6表示で、登録した育成段階とは別です。

## 3. 武具とメモリ

武具はカードを選んで詳細を開き、「所持品・サブ登録」からグレードやサブ効果を保存できます。一覧のパワーと並べ替えは「表示グレード」に連動します。所持品やアビリティで探すときは「絞り込み」を使います。メモリは「詳細・所持品を管理」から個体を追加します。同じ種類でも1個ずつ、呼び名とサブ効果を記録できます。似た個体は複製すると入力を省けます。

値が分からない場合は未確認にします。0は効果がないという数値、メモリの「枠なし」はその枠がない状態です。課金・入手先の条件で探すこともできます。

## 4. 研究と建設

研究の項目を開いて現在Lvを保存します。目標・経路を選び、資源と時間を見積もります。前提条件が未確認の項目では、その表示も確認してください。

施設では「調べるレベル」で外観と費用を確認し、「各棟の現在Lv」で自分の建設状況を登録します。「建設状況を保存」で確定します。調べるLvを変えただけでは、自分の現在Lvは変わりません。

## 5. 拠点アビリティの照合

内政・軍事・魔獣討伐を切り替え、名前や加算元で検索できます。「獲得済み」で登録済みの効果、「要確認」で未確認や差分がある効果に絞り込みます。

一覧の数値を押すと内訳が開きます。ゲーム内の合計を入力して「保存して照合」を押すと差分を表示します。加算元は種類別に開閉でき、必要なら未獲得分も表示できます。

未確認を含む合計は確認済みの小計です。「その他の効果」は自動集計されない効果だけに使ってください。武具・メモリの所持登録だけでは拠点効果に加算しません。

## 6. 編成のシミュレーション

「素材倍化率シミュレーター」で戦闘場所・種族を選び、所持エンバース、武具5部位、メモリの個体を選択します。同種メモリも別個体なら同時に選べます。研究・全所持コア・施設は拠点側で一度だけ集計し、雫を追加できます。所持・育成記録は変更されません。

「記録したゲーム内の拠点合計」は、自動集計を置き換えます。編成・武具・メモリ・雫を含まない値を登録し、二重加算を避けてください。「比較元」に現在の結果を控えると、入れ替えによる差を確認できます。

「種族別攻撃力シミュレーター」は同じ操作で攻撃力の補正%を比較できます。領域改稿では集結効果を、レイドでは雫を除外します。兵種は100%編成、属性は選択したリーダーから判定します。チャージ・アクティブの一時バフ、敵防御、兵士の基礎攻撃力などを含む実ダメージは計算しません。条件付きトリガーは発動条件を選択してください。

## 7. バックアップと共有

「記録とバックアップ」から定期的に書き出してください。別PC・別ブラウザー・公開URLへ移すときは、新しい画面でそのファイルを復元します。内容の確認後に置き換え、復元前の記録も別ファイルに書き出します。

同盟へ育成状況を渡す場合は「同盟ルーム」の共有用ファイルを使ってください。全体バックアップには個人メモなども含まれます。自動同期は行いません。

## 記録が見つからないとき

以前と同じブラウザー・プロファイル・URLか確認してください。`localhost` と `127.0.0.1`、異なるポート、ローカルURLと公開URLは別の保存先です。「プレイヤーを切り替え」に別の記録がないかも確認してください。

元の画面に記録があれば、バックアップを書き出して移行できます。サイトデータを消す前に必ず書き出してください。ログアウトだけでは記録は消えません。
