# 目標達成プラン（2026-10-28）

素材倍化率・種族別攻撃力シミュレーターの単部隊画面に追加。

1. 現在の編成を選択し、研究・施設・育成状況を登録する。
2. 画面下部「目標達成プラン」で合計の目標%を入力する。
3. 必要に応じて、サブ能力で狙う追加量をポイントで入力する。
4. 「組み合わせを提案」で時間優先・資源優先・追加量優先の3案を比較する。
5. 案を選び、候補一覧のチェックで組み合わせを調整する。選択した項目の効果の現在値・目標値・差分、前提項目、4資源と作業時間合計を確認する。

目標値・サブ計画は既存の「編成を保存」で保存する。取得候補の手動チェックは画面内の試算用で、編成や進捗を変更しない。種族・編成・進捗等の変更後は再提案する。

## 計算範囲

- 登録済みの現在Lvから、研究、施設、コア、選択中のエンバースのトリガー、武具のメイン効果の増分を計算。
- 研究の前提研究・研究所Lv、収録された前提施設を含む。共通の前提項目・複数段階を重複計上しない。
- 現在の速度・資源効率・固定加速で見積もる。待ち時間、並行作業、途中で増える補正、同盟支援や雫は含めない。
- 資源優先は4資源の個数合計を比較。追加効果に対する費用を順に比較する探索であり、全組み合わせの最適性は保証しない。
- 未確認効果を0と確定しない。費用未確認は既知分に「＋ 未確認」を付け、除外して探索する設定も用意。
- 拠点を手動合計または反映なしにした場合、研究・施設・コアの取得案は対象外。
- 新しい武具・メモリへの入れ替えは既存の編成画面で比較する。取得・強化案とランダムなサブの獲得は保証されない。

## サブ能力の確認例

ユーザーからの確認値：対種族別攻撃力はG1・13000パワー装備で113%。素材倍化率はメモリ第3サブ枠で14.3%。条件の違う武具へ一律換算せず、確認例との差分を参考表示する。素材倍化率は武具サブ候補・計算から除外し、過去の記録自体は保持する。

## NEWの期限

`public/whats-new.js` の項目別更新日から14日間。日付のみの入力は日本時間0時を起点にする。既存コンテンツは2026-10-17、目標プランナーと該当ナビ項目は2026-10-28。研究項目の `addedAt` も使用する。ページを開いたままでも毎分と画面復帰時に期限切れ表示を除去する。後日の追加では該当項目の更新日を変更する。

## 検証

期限の境界、前提条件の共有、段階の重複、既取得分の控除、資源・時間による選択差、未達、未確認、サブの条件差、実データでの探索、保存・読込・候補選択・進捗変更時の再計算を自動テストで確認。
ブラウザーでの目視確認は、操作ツールがWindowsの接続先URLを確認できず停止したため未実施。
