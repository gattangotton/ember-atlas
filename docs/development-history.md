## PC版マスターの共通データ（2026-10-03）

インストール済みPC版の `Ability`・`Equipment`・`Research` キャッシュを読み取り、アプリの武具194件と研究419項目を照合しました。共通データは `public/data/game-masters.json` です。ゲームのインストールがない別PCでも、このアプリとともに利用できます。

- 武具194件：段階別メインアビリティ3,031値とパワーを収録。マスターに5段階しかない武具8件のG6は空欄です。サブアビリティの抽選値・確率は今回の対象外です。
- 研究401項目：各Lvの合計効果1,981値を収録。18項目は兵種等の解放で、数値効果を補っていません。系統・名称・必要研究所Lvの組み合わせで全419項目を一意に対応付けています。資源・基本時間も全Lvをマスターに置き換え、旧資料との実数差2,557セルを記録しました。前提研究の登録方法は従来どおりです。
- 割合型の保存整数は100で割り、人数・基礎攻撃力などの整数型と区別しています。例：エクスカリバー(FFBE)の攻撃力は37.5／46.88／56.25／65.63／75／84.38％。画面・旧資料の小数1桁表示とは差があります。
- 旧共通初期値にあった拠点・研究所Lv8「対魔獣攻撃力」のLv5を14％から15％へ更新。資源生産4項目と資源保護1項目の初期値の単位も％に修正します。
- 保存済み武具の空欄は一致する効果のマスター値で補完し、手入力の数値は優先します。研究も空欄と旧共通初期値を更新し、別途編集した数値・前提条件・メモを保持します。所持数・育成Lv・プレイヤーの進捗は変更しません。

抽出元3ファイルのSHA-256・バージョンと各マスターIDは共通データ内、旧資料との差分は `artifacts/game-master-import-report.json` に記録しています。原本キャッシュや認証・アカウント・個人の進捗データは配布ファイルに含めていません。

再抽出：`node tools/import-game-masters.mjs <マスターキャッシュのフォルダー>`。フォルダーには `Ability`・`Equipment`・`Research` と各 `.version` が必要です。MessagePackを読み取り、型・段階数・ID対応を検証して共通JSONを生成します。曖昧な対応付けや未対応形式では停止します。更新後はアプリを再読み込みしてください。

### 施設・エンバース・画像の追加照合

- `game-masters.json` の施設データは Building ID と名前を照合した16施設と属性別祭壇7種。旧資料485段階のうち472段階に補完・修正があり、全段階の必要資源・基本秒数を置き換えます。各Lvの画像IDで外観を切り替え、同じ外観のLvでは画像を共用します。差分は `artifacts/game-world-audit.json`。
- `public/data/game-heroes.json` に72名、5スキル×全Lvの2,376説明、数値表、累積コアを収録。シグルドリーヴァ[葬姫]を追加しました。既存71名のIDは保持。古い共通設定・サイト値・旧スキル上書きよりゲーム設定を優先し、更新後に編集した値は引き続き編集値を使用します。旧保存データは削除しません。
- バフは自分・味方への強化（自身の次回スキル強化を含む）、デバフは敵への弱体。純粋な回復・状態異常解除と種族特効ダメージはバフに数えず、説明・数値を別途保持します。チャージ／アクティブ両方を対象に絞り込みます。144スキルの分類は `artifacts/game-hero-audit.json`。
- キャッシュ画像：武具194点、エンバース72点、施設外観115点、属性7・兵種4アイコン、レイド6体。`public/assets/game` と `game-image-paths.js` に収録。エンバース画像は常にG6背景を初期表示し、所持や育成段階とは連動しません。武具は一覧の選択G、詳細の画像段階選択に連動します。
- ゲーム内Help 131に合わせ、同盟支援を回数として扱い、毎回「残り時間の1％・最低60秒」を減算、0秒を下限とします。速度補正→固定秒数の順序、称号1.1倍の乗算順序もゲーム内ヘルプに整合します。整数に不要な小数点以下は表示しません。
- 限界：支援を直ちに受ける見積もりです。ゲーム実行コードの端数処理、資源効率除算式、支援の実際のタイミングは設定ファイルだけでは確定できません。これらは見積もり条件として画面に明記しています。

再生成は `import-game-masters.mjs` → `import-game-world.mjs` → `import-game-heroes.mjs` → `publish-game-images.mjs` の順。後半3つは `.work/game-master` のマスターを参照します。画像は `index-game-assets.mjs` → `extract-game-images.py`（UnityPy 1.25.3）でローカルキャッシュから抽出。カタログのハッシュが古い場合も同一バンドルIDの保存済み更新版を読み、画像パスで照合します。ゲーム側ファイルは変更しません。

### 施設表示とメモリの個別管理

- 施設の数値表示は小数第2位を四捨五入し、小数第1位まで表示します。整数の `.0` は省略し、内部計算は元の精度を保持します。外観画像は現在Lvの登録欄と横並びにし、調べているLvを明記しました。
- 「メモリ」にPC版 `Enhancer` の名前付き82種類を収録しました。同じ種類を複数登録でき、1個ずつ呼び名・最大3枠のサブアビリティ名／値／単位・メモを保存できます。「未確認」「枠なし」「登録済み」を区別し、未確認値を0に置き換えません。
- 所持メモリはプレイヤー別に保存し、全記録バックアップと復元に対応します。所持するだけでは拠点アビリティに加算しません（ゲーム内では装着した部隊への効果です）。
- 固定効果がマスターにない「忘れられし者」「テンプルドラゴン」は未確認表示です。現在のローカルキャッシュにメモリ画像は見つからず、代替アイコンを表示します。抽選候補・確率・育成段階の数値は推定していません。
- 共通データは `public/data/game-memories.json`、抽出結果は `artifacts/game-memory-audit.json`。再生成は `node tools/import-game-memories.mjs`（`.work/game-master` の `Enhancer`・`Ability` と各 `.version` を参照）。

## 使える機能

- 図鑑: エンバース71件、装備146件。キャラは属性・兵種のアイコン検索、カード／表表示、比較、お気に入り。装備は部位階層・メイン効果・G1パワーで検索。
- エンバース: 動画から71人分の顔画像を収録。画像取り込みとトリミング、チャージ・トリガー最大Lv7／アクティブ最大Lv5、現在と目標のスキルレベル、対象・範囲・追加効果・段階別効果値を設定できます。
- コアアビリティ: 効果30種類を軸に、該当エンバースとⅠ～Ⅵを一覧表示。獲得時Ⅰ、スキル合計10／15／20／25／30でⅡ～Ⅵを表示します。
- 装備: 複数の固有メインアビリティG1～G6、レイド製作区分、抽選候補と確率を設定できます。詳細の「所持数・個別サブアビリティを登録」から複数個を管理し、各個体のG・目標・サブ効果名と％を保存できます。2枠目はG5以上、3枠目はレイド武具のG6のみ登録できます。既存の所持記録は1個として引き継ぎます。
- 研究: 5系統419項目を研究所レベル順に配置し、確認済みの前提関係を線で表示。資源・時間・個人の進捗を確認できます。
- 育成ノート: 所持状況、スキル／グレードの現在と目標、自分用メモを保存。複数プレイヤーを切り替えて個別に記録できます。
- 同盟ルーム: 育成記録を書き出し、受け取った仲間の記録を取り込んで比較。共有前に内容を確認できます。同じプレイヤーの新しい記録で更新できます。
- データ管理: キャラ・装備・アビリティを手動追加／編集。攻略データJSONの一括追加／更新。全記録のバックアップと復元。
- 元シート: 43シートの保存値を、セル位置とともに検索・参照。

## 同じG1％の成長値を適用

武具詳細の「メイン・サブアビリティを設定」でG2～G6のメイン効果を登録すると、同じG1開始％を持つ他の武具の対象一覧を表示します。「この武具だけ保存」または「他の武具にも適用して保存」を選択してください。効果名が異なっても、％単位かつG1値が一致する効果を対象にします。空欄の段階は既存値を保持します。個別に所持する武具のサブ効果は一括適用しません。

所持品の個別記録はプレイヤー切替・バックアップ復元・同盟向け共有にも含まれます。所持数を減らす場合は末尾の個体を削除する確認が表示され、「所持品を保存」で確定します。

## 共有の手順

1. プレイヤー名と同盟名を設定します。
2. 図鑑の詳細から所持・育成状況を記録します。
3. 同盟ルームで「自分の記録を書き出す」を選び、共有内容を確認します。
4. 保存したJSONファイルを、使用している連絡手段で同盟員に渡します。
5. 受け取った人が同じアプリの「仲間の記録を取り込む」で読み込みます。

現段階のURLはこのPC専用です。同盟員が別のPCで使うには、このアプリのフォルダーをそれぞれの環境で起動する必要があります。共通URL、招待制ログイン、自動同期は次段階の機能です。

## 保存について

記録は同じブラウザー・同じURLのローカルストレージに保存します。ブラウザーのデータ削除で消えるため、定期的にバックアップしてください。攻略データと育成共有ファイルの用途は別です。全体バックアップには私用メモや仲間の記録も含まれます。

GitHubで同期されるのはアプリのファイルです。別PCに育成記録を移す場合は「データ管理」で全体バックアップを書き出し、移動先で復元してください。バックアップには複数プレイヤー、研究進捗、手動設定、取り込んだ画像、共通パターンも含みます。`localhost`と`127.0.0.1`は保存先が別になるため、普段使うURLを統一してください。

「プレイヤーを切り替え」は同じブラウザー内のプロフィール分離です。所持・育成・お気に入り・研究進捗は個人別、攻略データ設定・共通パターン・仲間の共有記録は共通です。オンラインの本人認証ではありません。

段階別の数値はエンバース詳細の「スキル・コアの設定」、装備詳細の「メイン・サブアビリティを設定」から入力します。「上昇パターンを管理」で登録した数値列は複数項目に適用できます。適用は値のコピーで、パターンの後日変更は適用済み項目に連動しません。

## 元Excelの更新

元Excelは読み取り専用で扱い、一切変更していません。更新版Excelを再取り込みする場合は `tools/extract_database.py <Excelのパス>` を、openpyxlのあるPythonで実行します。キャラ名の変更でIDが変わるため、その場合は育成記録のID移行が必要です。手動追加・編集は端末側に独立して残ります。

## 収録範囲と制限

装備図鑑は元資料と動画の装備を146件に統合しました。110件に動画で確認したG1パワー・部位・メイン効果名と確認秒を収録しています。動画で確認した固有メインアビリティを追加し、グレードが特定できない資料の数値は出典付きメモに残しています。未確認の中間スキル値、コアⅠ～Ⅴ、抽選確率は推測で埋めていません。空欄は0とは別です。研究の未確認の前提関係は線を引いていません。研究の上限表示は資料の収録レベルです。

元シートの画像、図形、結合セルの外観、Excel数式再計算、個人補正を使う素材不足自動計算は未実装です。動画自体は配布ファイルに含めず、Lvやチャットのない顔の切り抜きのみ収録しています。

補足データの再生成は `node tools/build_mechanics.mjs`。動画からの画像抽出は `tools/extract_portraits.mjs` の引数を参照してください。元Excelと動画の出典・確認位置は補足データと画像索引に記録しています。

元ファイルには保存時点の数式エラーが99セルあります。確定値として補完せず、元シート画面で確認できます。ゲームの最新情報との照合は行っていません。

## 開発

依存パッケージなしのES modules + CSS + Node HTTPサーバーです。`npm test` で抽出・検索・共有データ・入力検証のチェックを実行できます。設計と次段階の共有構造は `DESIGN.md` に記録しています。

## 図鑑の絞り込み

初期表示は☆5スタートです。☆4・☆3・全レア度はボタンで切り替えます。動画から切り抜いた属性・兵種アイコン、所持状況、チャージの単体／複数・範囲・追加効果を組み合わせられます。「各スキルの育成状況」で未登録・育成中・最大・目標未達・個別Lvを選択できます。条件はANDで適用し、バフ／デバフには両方を持つスキルも含みます。追加効果が未確認のキャラは未確認ボタンで探せます。

画像71人分を照合済み。ウラノスの旧画像取り違えを修正しました。通常版エプレは追加スクリーンショットから収録しました。

## エンバースの基礎データと発動状態

エンバース直下の「基礎データ」でチャージ・アクティブ・トリガー・コアを追加、編集、複製できます。既存資料の同一内容をまとめた項目も初期表示されます。効果名・単位・育成Lvごとの数値・出典・条件を入力し、「キャラに適用」でコピーします。トリガーは1～3の適用先を選択できます。コアの適用はそのキャラのコア効果全体を置き換えます。

キャラ詳細の「発動段階・スキルの詳細設定」では、そのキャラのスキルだけを編集でき、「基礎データにも新規登録する」も選択できます。通常／強化1／強化2や溜めLv1～3を独立した状態として追加し、それぞれの効果を育成Lvごとに登録します。アクティブの育成上限は5のままです。発動状態はコア解放の合計に加算しません。未確認値は空欄で保存できます。

ステラの育成Lv7威力1400／2800／4200、エプレの1400／2800と強化の解除条件はIMG_5703～5705から反映済み。中間育成Lvや未提示のアクティブの数値は推測していません。基礎データの変更は全体バックアップに含まれ、各プレイヤーで共通です。攻略データJSONには適用済みキャラの状態別スキルが含まれますが、独立した基礎データの移行には全体バックアップを使います。

属性・兵種のアイコンは検索、カード、一覧、詳細、コア比較に表示します。アイコンとエプレの画像の再生成は `tools/refine_screenshot_assets.py` にIMG_5688と動画20秒の1400px幅画像を渡し、その後 `node tools/build_mechanics.mjs` を実行します。元画像自体は配布データに含めません。


## 装備検索・施設建設（2026-09-26）
- 装備トップは検索用。武器・頭部・身体・脚部・装飾の下位ページでも検索条件を維持します。動画の60種類のメイン効果をAND/ORで選択し、G1パワーと組み合わせられます。
- カード右上のパワーとメイン効果は表示Gに連動します。エクスカリバーはG5/G6の値も収録。未確認の段階は自動補間しません。
- パワー別の成長パターンは、G1パワーと効果の組み合わせごとに登録・編集・削除できます。同じG1パワーの装備にコピー適用します。パワーが同じでも異なる効果構成への自動適用はしません。
- 「施設建設」は16施設・485段階。施設検索、分類、Lv切替、4資源と基本時間、全Lv比較、出典差異の表示に対応しています。現在Lvの保存や短縮計算は行いません。
- 建設時間計算機を主な出典とし、別表と異なる210段階は差異を表示。研究所Lv31の資源は単位が不明なため未確認。祭壇は別シートのk/M表記と照合してMから個数に換算しています。
- Excelに前提施設Lvの一覧は見つからないため未確認です。確認後に施設と必要Lv、メモを手動登録できます。前提施設ボタンから該当Lvへ移動できます。
- 成長パターンと施設の前提条件は全記録バックアップに含まれます。ブラウザー内で手動登録した内容はGitHubのファイル同期とは別にバックアップを移行してください。
- 施設データの再生成: `node tools/build_buildings.mjs`（既存の `public/data/sheets.json` を読み取り）。装備データの再生成: `node tools/build_mechanics.mjs`。

## 拠点アビリティと研究計画（2026-09-27）
- `#baseAbilities`：内政・軍事・魔獣討伐のタブ。研究の現在Lv、所持エンバースのコア段階、登録済みの施設等の加算元を合計し、ゲーム内の手入力値と比較します。内訳には各加算元の場所・段階・数値を表示します。
- 未獲得は0。獲得済みでも効果が不明なら未確認として表示し、確認済み小計と区別します。動画の105項目の数値は参考値で、個人の進捗に自動登録しません。
- 施設・装備・称号・アイテムは「施設・その他の加算を登録」で現在の効果を登録します。施設Lv変更に伴う効果の自動更新は未対応です。
