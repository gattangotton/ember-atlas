# 背景画像

ユーザー提供の画像3枚を加工せず保存。battlefield.png（戦場）、embers.png（エンバース）、city.png（拠点）。ゲーム画像の権利は各権利者に帰属します。

2026-10-01に公式世界観ページ https://www.jp.square-enix.com/emberstoria/story/ も候補として確認。公式画像の取得に失敗したため追加素材は採用していません。

背景はCSSの白いベールで薄め、フォームや数値の不透明なパネルと分離しています。施設の属性ごとの登録データには変更を加えていません。

追加のユーザー提供画像：ensemble.png（赤い集合絵／エンバース）、arca.png（空中都市／ダッシュボード・同盟・データ管理）、confrontation.png（紫の対峙／レイド武具）。画像自体は変更せず、色の強い集合絵は白いベールを濃くして表示。
